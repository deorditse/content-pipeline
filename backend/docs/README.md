# Docs: Backend

Документация проекта `backend`.

- `specs/todo/` — активные OpenSpec-спецификации задач.
- `specs/done/` — завершённые/принятые спецификации.
- `adr/` — архитектурные решения и правила.
- `templates/` — шаблоны документов.

## ADR файлы

- `adr/rules.md` — архитектурные правила проекта. Пока пустой.
- `adr/agent.md` — инструкции для агентов по проекту. Пока пустой.
