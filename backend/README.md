# Backend

Заглушка backend-проекта.

План: FastAPI + OpenAPI.

## Будущие модули

- `briefs` — входные идеи/брифы.
- `scripts` — генерация сценария и сцен.
- `assets` — картинки, видео, аудио, субтитры.
- `providers` — адаптеры к моделям TTS/image/video.
- `render` — сборка итогового Reels MP4.
- `jobs` — фоновые задачи и статусы.
