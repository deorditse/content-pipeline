# Frontend

Заглушка frontend-проекта для UI конвейера контента.

Пока стек не выбран. Возможные варианты:

- Next.js/React — если нужен полноценный web UI.
- Vite/React — если нужен лёгкий SPA.
- Telegram WebApp — если хотим управление прямо из Telegram.

## Будущие экраны

- Бриф / идея ролика.
- Сценарий и сцены.
- Prompt editor для картинок/видео.
- Очередь генераций.
- Preview сцены и итогового ролика.
- Экспорт и история проектов.
