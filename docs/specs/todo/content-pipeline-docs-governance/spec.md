# Content Pipeline: OpenSpec документации и ADR

## Цель
Ввести единый слой документации OpenSpec/ADR для репозитория content-pipeline и связать подпроекты через map.md.

## Контекст
Корневой проект описывает общий конвейер Reels/shorts: сценарий, сцены, генерация ассетов, озвучка и сборка ролика.

## Что делаем
- Создать/поддержать `docs/adr/` как место архитектурных правил.
- Добавить пустые `docs/adr/rules.md` и `docs/adr/agent.md` для будущих правил.
- Добавить корневой `map.md` как быстрый навигатор по проектам репозитория.

## Что НЕ делаем
- Не выбирать технологический стек сверх уже описанных заглушек.
- Не заполнять архитектурные правила без отдельного решения.
- Не менять продуктовый scope конвейера.

## Критерии приёмки
- `docs/adr/rules.md` и `docs/adr/agent.md` существуют.
- `map.md` перечисляет корневой проект и подпроекты с ответственностями.
- Spec задачи находится в `docs/specs/todo/`.

## Открытые вопросы
- Какие архитектурные правила первыми занести в `rules.md`?
- Какие инструкции для агентов должны попасть в `agent.md` после выбора рабочих процессов?
