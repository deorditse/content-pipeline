# Bootstrap Content Pipeline

## Цель

Создать стартовую заготовку проекта для будущего конвейера генерации Reels/shorts-контента.

## Контекст

Нужно подготовить рабочую директорию и GitHub-репозиторий под дальнейшую разработку: FastAPI + OpenAPI backend и отдельный frontend-проект. На этом этапе реализация бизнес-логики не требуется.

## Что делаем

- Создаём проект в `/home/dmitrii/work/deor_creator/content-pipeline/`.
- Добавляем README и базовую структуру.
- Добавляем backend-заглушку под FastAPI.
- Добавляем frontend-заглушку.
- Добавляем research-заметку по Хабру о TTS/image/video моделях для Reels.
- Инициализируем git и создаём GitHub-репозиторий.

## Что НЕ делаем

- Не реализуем полноценный API.
- Не подключаем реальные провайдеры генерации.
- Не храним ключи, токены или приватные API responses.
- Не публикуем ничего в соцсети.

## Критерии приёмки

- Директория проекта существует в workspace профиля.
- Есть `README.md` с назначением и будущей архитектурой.
- Есть `backend/` и `frontend/` заглушки.
- Есть research-файл с первичными выводами.
- Workspace map обновлена.
- GitHub repo создан и ссылка отправлена Дмитрию.
