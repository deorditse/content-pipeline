# Content Pipeline

Заглушка проекта для конвейера Reels/shorts-контента: сценарий → сцены → картинки/ключевые кадры → видео → озвучка → сборка ролика.

## Цель

Собрать рабочий продуктовый пайплайн для генерации коротких вертикальных роликов с озвучкой и визуалом по сценам.

## Планируемая архитектура

- `backend/` — FastAPI API + OpenAPI, оркестрация задач, интеграции с моделями озвучки/картинок/видео.
- `frontend/` — отдельный фронтенд-проект для UI управления пайплайном.
- `research/` — заметки по моделям, сервисам и решениям.
- `docs/` — спецификации задач, ADR и шаблоны.

## MVP-пайплайн

1. Ввод идеи/брифа для Reels.
2. Генерация сценария и разбивка на сцены.
3. Для каждой сцены: промпт изображения, стиль, референсы, длительность.
4. Генерация ключевых изображений/кадров.
5. Генерация/анимация видео по сценам.
6. Генерация озвучки и субтитров.
7. Сборка вертикального ролика через FFmpeg/moviepy.
8. Экспорт итогового `.mp4` + метаданные промптов и затрат.
